# Ellipsis

> Ellipsis is a managed cloud platform for running autonomous coding agents at scale. Engineering teams define agents as YAML config files that live in their repositories, and Ellipsis runs them in isolated, ephemeral sandboxes to review pull requests, fix bugs, build features, and investigate production issues. Agents trigger on cron schedules, GitHub pull-request lifecycle events, or @ellipsis-dev mentions, and can be launched on demand from the dashboard, the REST API, or the `agent` CLI. Runs Claude, Codex, and Gemini models; enforces hard budget caps and scoped per-session credentials; retains zero source code. Ellipsis (YC W24) serves 400+ engineering teams across 67,000+ repositories.

## APIs

- [Ellipsis API](https://www.ellipsis.dev/docs/reference/api): REST API (base https://api.ellipsis.dev) — start/manage agent sessions, read typed results and transcripts, manage configs/defaults/templates, sandbox variables, integrations, analytics, assets, budget, and usage. Bearer-token authenticated.
